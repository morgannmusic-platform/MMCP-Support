Comment créer une sortie ?

Bienvenue sur ce guide.
Pour commencer veuillez vous connecter à votre compte sur
la page de connexion.

1. Préparation de toutes les métadonnées

Avant de vous lancer dans la création de votre sortie sur votre portail artiste, assurez-vous d'avoir sous la main les éléments suivants :

  • Vos fichiers audio au format maître (WAV 24-bit / 44.1kHz minimum,
    Dolby Atmos(optionnel), intrumental (optionnel)).
  • Votre pochette au format carré (minimum 3000 x 3000 pixels en RGB).
  • Les autres informations exactes de votre sortie :
    Dates (original, precommande, heure, zone géographique), crédits, UPC/ISRC, etc (pour voir plus regardez sur votre éditeur de sorties).

2. Préparez la sortie sur Nouvelle.

Rendez-vous sur votre portail artiste, dans la bar de navigation, cliquez sur action catalogue puis sur Créer une sortie.

  • Sur cette page séléctionnez le type de sortie que vous voulez (abum, single, EP, Compilation).
  • Entrez le titre de votre sortie.
  • Séléctionnez à quelle artiste de votre compte apparartient la sortie.

Félicitation ! Vous venez de créer la sortie sur votre compte.

3. Completez les informations de votre sortie.

Accedez à l'onglet Pochettes.

Vous pouvez cliquer sur Importer la pochette
Optionnel mais recommandé : Importez des Apple Motion Art.


Accédez à l'onglet Information Sortie.

  • Choisissez vos dates.
  • Choisissez le genre de votre sortie.
  • Choisissez la langue de votre sortie ou si celle-ci est instrumental.
  • Choisissez la ligne copyright qui sera affiché sur les plateformes
  • Optionnel : Choisissez les plateformes à qui nous distriburons votre sortie.
  • Optionnel mais recommandé : Ajoutez les livraisons additionnels.
  • Optionnel : Choisissez une version, un code UPC, les pays à qui nous distriburons la sortie et plus.

Accédez à l'onglet Pistes.

Cliquez sur + Importer de nouvelles pistes ou séléctionnez des pistes de votre bibliothèque.
Dès que vos pistes sont importées, cliquez sur le boutons modifier sur l'une de vos pistes.

Dans l'onglet Information

  • Choisissez le nom de votre piste.
  • Optionnel : Choisissez la version de votre piste.
  • Indiquez si votre piste contient des éléments générés par
    Intelligence Artificielle.
  • Indiquez la langue de vos praroles.
  • Definnisez un code ISRC
  • Definnisez un code ISWC

Dans l'onglet Participants

  • Indiquez les écrivains et parolies.
  • Inquiquez les crédits Apple Music structurels.

Dans l'onglet Audio étendu

  • Optionnel : Importez une piste Dolby Atmos visible sur Apple Music, Tidal & Amazon Music.
  • Optionnel : Importez une piste Instrumental.

Dans l'onglet Paroles

  • Choisissez le type de paroles (clean, explicit)
  • Collez ou transcrivez vos paroles.

Vous pouvez maintenant cliquer sur Valider

Verfiez toutes les information de votre sortie et si celle-ci est prête vous pouvez cliquer sur Publier
